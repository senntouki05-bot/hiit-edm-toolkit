# hiit-edm-toolkit

HIIT（高強度インターバル）向けの EDM を作るための2つの道具です。

1. **プロンプト生成**（`index.html`）：運動／休憩の秒数に合わせた構成の EDM を Suno で大量に作るための、プロンプト（Style・構成タグ）を量産します。ブラウザで開くだけで動きます（サーバ不要・通信しません）。
2. **hiit-cut**：Suno で作った曲を解析して、HIIT の秒数どおりに小節単位で組み直し、mp3 にします。

Suno はプロンプトで秒数を守らないことを実測したため、「素材は Suno で作り、秒数は後工程で固定する」という分担にしています。

## プロンプト生成

`index.html` をブラウザで開き、HIIT のプロトコル（Tabata・10-20-30・40/20 など）・サブジャンル・ボーカルの有無・本数を選んで「プロンプトを生成」を押します。各カードの Style と構成タグを Suno にコピーします。まとめて TXT / CSV / JSON に保存することもできます。

秒数は「BPM × 小節数」で近似します（4/4 で 1小節 = 240 ÷ BPM 秒）。各カードに区間ごとの実秒と累積のズレを出します。同じシードを入れると同じ結果を再現できます。

| プリセット | 構成 | 出典 |
|---|---|---|
| Tabata | 20/10 × 8 = 4分 | Tabata et al. 1996 |
| 10-20-30 | 30低 → 20中 → 10全力 × 5 | Gunnarsson & Bangsbo 2012 |
| 7-Minute Workout | 30/10 × 12 | Klika & Jordan 2013 |
| SIT | 30全力 / 240回復 × 4 | Gibala et al. 2006 |
| Norwegian 4×4 | 240 / 180 × 4 | Helgerud et al. 2007 |
| 30/30・40/20・45/15・EMOM | スタジオ定番の構成 | 慣習 |

## hiit-cut

```bash
bash h ui                                   # ブラウザで曲をドラッグ → プロトコル選択 → mp3 を作成
bash h cut song.mp3 --preset tabata --beep  # 曲を Tabata の秒数に組み直す（ビープ付き）
bash h cut song.mp3 --segs 30:low,20:mid,10:work --rounds 5
bash h analyze song.mp3                     # BPM・小節・高/中/低の分布だけ見る
bash h test                                 # 合成曲で自己テスト
```

仕組み：

1. テンポを推定して小節の頭を求め、小節ごとの音量（RMS）を測ります。
2. 小節を高・中・低に分け、種別に合う区間から小節の頭で切った素材を貼ります（全力＝高、休憩＝低、イントロ＝曲頭の低、アウトロ＝曲末の低）。
3. 可能なら、全区間が整数小節になるテンポへわずかに伸縮して、継ぎ目を拍に乗せます。無理なときは小節の頭からちょうど N 秒で切ります。
4. 任意でビープ（-3・-2・-1 秒と GO）とコーチの音声（macOS の `say`）を秒数ぴったりに重ねます。
5. -14 LUFS に整え、**出力の長さが合計秒数と一致することをサンプル単位で検証します**（ずれたら失敗として止まります）。

必要なもの：Python 3.12、`librosa` `soundfile` `numpy`（`h` の初回に作り方が表示されます）。

## 限界（正直なところ）

- 動作の確認は合成曲だけです。**Suno が実際に作った曲では未検証**です。
- 高・中・低の分類は音量だけで行うため、音量差の小さい曲では、全力の区間に盛り上がっていない所が入ることがあります。`analyze` で分布を見て、合わない曲は捨ててください。
- テンポが一定の EDM（100〜200 BPM）が前提です。テンポが揺れる曲は対象外です。
- 継ぎ目は別の場所の小節をつなぐので、フレーズの途中で飛ぶことがあります。
