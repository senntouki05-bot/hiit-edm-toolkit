# HIIT EDM Prompt Factory（Suno用プロンプト量産ツール）

HIIT（高強度インターバル）の運動/休憩の秒数に合わせた構成のEDMを、Sunoで大量に作るためのプロンプト生成ツール。
**テーマは「HIIT向けEDM」の1つだけ。**

## 使い方
1. `index.html` をブラウザで開く（ダブルクリックでOK・サーバ不要・ネットに出ない）
2. 左で HIITプロトコル（Tabata / 10-20-30 / 40/20 …）・サブジャンル・ボーカル有無・本数を選ぶ
3. 「プロンプトを生成」→ 各カードの **Style** と **Lyrics（構成タグ）** を Suno の Custom モードへコピー
4. まとめて出すなら TXT / CSV / JSON 保存

Sunoでの貼り先:
- **Title** → Title
- **Style of Music** → Style of Music（v4.5系は1000字・旧版は200字上限＝左で切替）
- **Lyrics / 構成タグ** → Lyrics（インストは先頭に `[Instrumental]` が入る）

## 仕組み（秒→小節）
Sunoは「何秒」を守らないので、**BPM×小節数**で近似させる。4/4で 1小節 = 240/BPM 秒。
例: 128BPM → 16小節=30.0s、5小節=9.4s。各カードの「タイムライン換算表」に区間ごとの実秒と累積ズレを出す（3秒超は黄色）。

## 注意
- 1曲の上限は v4系≈4分・v4.5系≈8分（**公開情報ベース・未実測**）。4分超は4分ブロックで作り Extend で繋ぐ。
- 「圧縮表記（Repeat the following block N times）」はSunoが解釈する保証なし。既定は全区間を展開。
- シードを入れると同じ結果を再現できる（テスト済み）。
- 生成したプロンプトを実際にSunoへ投げた結果は**未検証**。最初の数本で「ドロップが10秒区間に来るか」を耳で確認してからまとめて回す。

# hiit-cut（後工程で秒数を固定する・2026-08-29追加）

Sunoはプロンプトで秒数を守らない（実測）。なので**Sunoでは素材だけ作り、後工程でHIITの秒数どおりに組み直す**。

## 使い方
- GUI: `bash ~/dev/hiit-edm-prompts/h ui` → ブラウザが開く → 曲（mp3/wav・複数可）をドラッグ → プロトコル選択 → 「組み立てる」 → mp3 をダウンロード
- CLI: `bash ~/dev/hiit-edm-prompts/h cut 曲.mp3 --preset tabata --beep`／`--segs 30:low,20:mid,10:work --rounds 5`
- 解析だけ: `bash …/h analyze 曲.mp3`（BPM・小節・高/中/低の分布）
- 自己テスト: `bash …/h test`
- 出力: `out/<プロトコル>/<曲名>_<プロトコル>.mp3 / .wav / .json`（JSON=どの区間にどの小節を使ったかのキューシート）

## 仕組み
1. 解析: 大域テンポ推定 → 周期×位相のグリッド探索でオンセット合計を最大化（一定テンポのEDM前提・100〜200 BPM）→ 小節頭（4/4）→ 小節ごとの RMS
2. 小節を高/中/低（40/65パーセンタイル）に分類し、連続する塊（run）にまとめる
3. 各区間へ、種別に合う run から小節頭で切った素材を順に貼る（**全力=高／休憩・低=低／中=中／イントロ=曲頭の低／アウトロ=曲末の低**）
4. 可能なら「全区間が整数小節になるBPM」へ atempo でストレッチ（既定の許容10%・継ぎ目が拍に乗る＝grid モード）。無理なら小節頭からちょうどN秒で切る（exact-cut モード・秒数は同じく固定）
5. 任意でビープ（-3,-2,-1秒＋GO音）・コーチ音声（macOS `say`）を秒数ぴったりに重ねる
6. -14 LUFS へ正規化して WAV/MP3。**出力の長さ = 合計秒数をサンプル単位で検証**（ズレたら失敗で止まる）

## 検証（2026-08-29・合成曲）
128BPM・8小節ごとに ドロップ/ブレイク 交互の合成曲で、Tabata（300s）と 10-20-30（360s）を組み立て:
長さ一致（サンプル単位）／全力 −13.5dB vs 休憩 −20.8dB／全力開始の境界8/8で直前→直後に+4dB以上／grid（128→120BPM）と exact-cut 両モード。UI は GET/POST/ダウンロードを curl で通し。

## 未検証・限界（正直に）
- **Sunoの実曲では未実測**。ドロップ/ブレイクの分類は音量だけなので、音量差の小さい曲では全力区間に「盛り上がっていない所」が来うる → `analyze` で分布を見て、ダメな曲は捨てる
- 継ぎ目は30msフェードの突き合わせ。gridモードでも「別の場所の小節」を繋ぐので、フレーズの途中で飛ぶことはある
- テンポが揺れる曲（ライブ感・ブレイクでテンポ変化）は前提外
- ストレッチは音質が落ちる（既定は10%まで。0にすると常に秒切り）
- 曲の種別が「高」しかない（ずっとドロップ）場合は休憩区間にも高が入る（PREFERの順で代替）
